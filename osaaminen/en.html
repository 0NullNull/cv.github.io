How I work

Practices

With the users

Features come from talking with the people who use the application, and they improve based on their feedback.

Security from the start

Permissions are checked on the server for every read and write, never left to the user interface.

Clear boundaries

One shared data model and one API for the business logic, used by every user interface.

Tests and monitoring

Automated tests in a CI pipeline, clear error codes and incident tracking, so problems are found quickly.

Owning production

I release, monitor and maintain what I build, so I design every change so that it can be rolled back.

AI-assisted development

I use agent-based development guided by maintained architecture documentation. Every change is reviewed before it is released.
